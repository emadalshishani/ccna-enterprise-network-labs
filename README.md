# CCNA Enterprise Network Labs

Progressive Cisco Packet Tracer lab series documenting the evolution from basic campus switching to a routed three-tier enterprise design.

## Lab progression

1. Basic Campus Topology
2. Two-Tier Campus Topology
3. VLAN Segmentation
4. Rapid-PVST+ and EtherChannel
5. CIDR Addressing and Gateway Model
6. Three-Tier Architecture and Static Routing
7. OSPF Area 0
8. Floating Static Route and IPv6 Static Routing
9. HSRP First-Hop Redundancy

## Topics

- VLANs and 802.1Q trunking
- Rapid-PVST+ and STP root placement
- EtherChannel / LACP
- Multilayer switching and inter-VLAN routing
- CIDR and subnetting
- IPv4 static and floating static routes
- OSPF Area 0
- IPv6 addressing and static routing
- HSRP
- Verification and troubleshooting

Detailed documentation is organized under `docs/`.

> The labs are intentionally sequential. Later Packet Tracer files retain configuration and experiments from earlier stages, reflecting the actual learning progression rather than isolated exercises.

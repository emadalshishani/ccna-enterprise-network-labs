# 01 — Basic Campus Topology

## Objective

Establish the initial campus switching topology and a baseline for later Layer-2 and Layer-3 additions.

## Focus

- Basic Ethernet switching
- Initial device and endpoint connectivity
- Interface and reachability verification

## Progression

This is the starting state of the series. Later labs build directly on this foundation by adding additional access segments, VLANs, STP tuning, EtherChannel, routing, IPv6, and gateway redundancy.
